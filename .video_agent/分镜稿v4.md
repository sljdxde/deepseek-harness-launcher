# 分镜稿 v4 — Deepseek Harness Launcher（DHL）B 站宣传视频

- 定位：开源项目宣传（非企业宣传）
- 总时长：约 85–90s（四幕 18 镜，可超 1 分钟）
- 风格：参考 BV1p9et66ExZ —— 浅蓝白包装、真实 UI 录屏、短句大字字幕、镜头间淡入淡出转场
- 铁律：**全程鼠标点选，不演示任何快捷键**；所有演示均为项目真实功能；封面/包装卡不用 AI 生成图（复用已有 gfx 或用户自制）
- 输出：1280x720@30，顶部裁豆包横幅（y160 起），底部裁 Dock（高 1830），字幕 ASS 浅蓝白，BGM 音量 0.3 + 旁白 +6dB
