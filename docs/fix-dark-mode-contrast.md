# 修复：夜间模式下设置窗口的文字看不清

## 现象

系统切到深色外观后，启动器设置窗口出现两类看不清的地方：

1. **勾选框只剩几个白色小勾，标签文字几乎消失**；
2. 卡片被画成**浅色底**（近乎纯白），配白色文字糊成一片。

用户描述为「夜间模式下，字体看不清」。

## 测量

不靠肉眼判断，直接放大用户截图逐像素取色，再按 WCAG 2.1 算对比度：

| 位置 | 前景 | 背景 | 对比度 | 判定 |
|------|------|------|--------|------|
| 勾选框标签 | `#070808` | `#1D1E1E` | **1.20:1** | 远低于 AA 4.5:1 |
| hint 小字 / 版本号 | `#555656` | `#1D1E1E` | **2.27:1** | 低于 AA |
| 卡片标题（对照） | `#999999` | `#1D1E1E` | 5.87:1 | 正常 |

`#070808` 是**浅色模式下的正文色**画在深色卡片上——这直接指向根因。

## 根因（两个独立缺陷）

### 1. 勾选框标签没有显式颜色

`NSButton(checkboxWithTitle:)` 的标签走 `attributedTitle`，而 `contentTintColor`
**只影响开关字形，不影响标签文字**。深色窗口里标签被解析成近黑，于是只剩白勾可见。

修复：用 `attributedTitle` 显式写 `NSColor.labelColor`（动态色，两种外观都成立），
开关字形改用 `controlAccentColor`（未选中的灰框在深色下也只有 2.7:1）。

### 2. 动态颜色被 `.cgColor` 冻结

`layer.backgroundColor = NSColor.controlBackgroundColor.cgColor` 在**赋值那一刻**
就把语义色解析成固定 RGBA。窗口若先在浅色下创建、系统随后切到夜间模式，
图层仍停在浅色值。实测：

```
cgColor 冻结（浅色创建）切深色后: (255, 255, 255)   ← 纯白
期望深色卡片底 ≈ (29, 30, 30)
```

AppKit 不会替 `CALayer` 重新解析——`viewDidChangeEffectiveAppearance` 是唯一可靠的
时机。修复方式：新增 `Sources/DynamicLayerView.swift`，把「按当前外观上色」写成
闭包，构造时执行一次、每次外观变化重跑；`AlertDesign` 的卡片与通道胶囊同样改为
在 `viewDidChangeEffectiveAppearance` 里重设颜色。

### 3. 顺带修掉的层级灰

`tertiaryLabelColor` 实测深色 **2.26:1**、浅色 **1.88:1**，两种外观都达不到 AA。
它原本被用在 hint 小字、版本号、弹窗脚注、安装窗口说明等处。这些内容需要被读到，
一律改为 `labelColor`（层级改由字号表达）或 `secondaryLabelColor`；
纯装饰的分隔线改用 `separatorColor`；菜单禁用项改用语义色 `disabledControlTextColor`。

## 验证

- 真实 GUI 渲染（浅色创建 → 切深色，不重建视图），逐像素复测：

  | 位置 | 修复前 | 修复后 |
  |------|--------|--------|
  | 勾选框标签 | `#070808`（1.2:1） | `#DDDDDD`（≈12:1） |
  | 卡片底色 | `#FFFFFF` | `#1E1E1E` |
  | hint / 版本号 | `#555656`（2.3:1） | 正文色（≈12:1） |

  整窗亮像素占比从 63% 降到 6%，说明卡片不再被画成亮底。
- 新增 `scripts/test-contrast.swift`：按 WCAG 解析系统语义色在两种外观下的真实
  对比度（含 alpha 合成），并守卫「关键文案必须用正文色」「不许直接用 `.cgColor`
  冻结图层色」。
- 新增 `scripts/test-dynamic-layer.swift`：同一视图在浅色/深色下必须解析出不同的
  图层色，且切回浅色能恢复（防止单向固化）。
- `scripts/test.sh --fast` 与全量回归均绿。

## 教训

- **对比度是可以量的**：截图取色 + WCAG 公式，比「感觉有点淡」可靠得多；
  1.2:1 这种值一眼就能判定是 bug 而不是风格问题。
- **动态色只在「取值那一刻」有效**：凡是把语义色转成 `CGColor`、位图、字符串缓存
  的地方，都要问一句「外观变了谁来更新」。
- **测试也会固化 bug**：`test-alert-design.swift` 原本断言
  `note.textColor == .tertiaryLabelColor`，等于把「11pt 小字配 2.3:1 的灰」写成了
  正确值。断言应该描述意图（可读），而不是复述实现。
