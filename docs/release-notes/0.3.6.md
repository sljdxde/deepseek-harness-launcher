## 0.3.6 更新说明

### 新功能

- **安装/更新显示真实进度条**：安装与更新运行环境时，进度条从 0% 平滑推进到 100%，按「准备 → 解析依赖 → 下载包 → 安装 → 校验」五个阶段加权爬升，下载阶段按实际 tgz 包数量精确计数，并显示百分比。此前是无百分比、来回滚动的不确定动画，长时间等待时无法判断是否卡住。
- **归档会话支持一键还原**：归档管理窗口每行新增「还原」按钮，工具栏新增「还原选中」。还原时整个会话树（含全部子会话/后代）一起回到正常会话列表；不属于任何工作区的游离会话，会按其所在目录自动登记到路径匹配的工作区，不再出现「点了还原却哪里都找不到」的情况。

### 体验改进

- **运行环境的更新与重建全部改为先询问，不再自动执行**：
  - App 自带新版运行环境锁文件时，启动只问一次「更新运行环境 / 稍后」。选「稍后」照常启动当前版本，选择会被记住、不再反复询问，菜单栏常驻「更新运行环境到 vX（App 自带）」入口，随时可点。
  - 运行环境缺失时只问一次「重新安装 / 稍后」，菜单提供「重建 DeepSeek Harness 运行环境」，不会每次打开都弹窗打断。
- **运行环境替换中断可自动恢复**：若运行环境在替换中途被打断（只留下 `runtime.previous-*` 完整快照），启动器会自动把快照换回再启动，不弹重装框、不联网重装。卸载脚本同样只在正式运行环境已在位时才清理快照，绝不会删掉用户唯一一份运行环境。
- **插件卸载后引导重启**：卸载插件成功后会提示「是否立即重启 dsh」，确认后启动器自动重启运行环境，侧边栏入口立即刷新，无需再手动重启。
