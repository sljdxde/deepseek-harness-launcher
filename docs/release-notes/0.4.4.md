## 0.4.4 更新说明

本次是 0.4.3 的修正版：0.4.3 引入的弹层降级逻辑范围过宽，把「自己居中」的弹层也接管了，导致插件管理与归档管理界面排版错乱。

### 修复

- **修复 0.4.3 引入的弹层排版错乱**：点开「插件管理」「归档管理」后，弹层被挤到窗口左侧、内容被裁掉一半，几乎无法操作。
  - 原因是这两个界面用 `left:50%; top:50%; transform:translate(-50%,-50%)` **自己居中**，并且都带 `role="dialog"`；而 0.4.3 的降级脚本把带该角色的弹层一律当成「锚点弹层」接管，改写了 `top`/`left` 却没有清掉 `transform`，于是整个弹层又被推走自身尺寸的一半。
  - 现在改为**只接管真正依赖锚点定位的弹层**（有 `data-anchor-side` / `anchor-name` 等锚点声明），自带 `transform` 居中的弹层一律原样交给它们自己的 CSS。
  - 升级时会把旧版本留在弹层上的内联样式（`top`/`left`/`max-height`）还原，避免老用户升级后弹层继续偏着。
- **修复窗口刚创建时降级脚本可能失效**：脚本注入时机早于 `<html>` 建立，原先会因拿不到文档根节点而装不上监听。现在改为等 DOM 就绪后再装，菜单在旧系统上依然能被正确摆位。

### 回归

- 降级脚本新增三类回归用例：自带居中的弹层必须**不被改动**；带锚点声明的弹层仍要被接管；升级路径必须能还原旧版残留的内联样式。
- 三平台复查：macOS Universal 2（arm64 + x86_64，含 Intel Mac）全量回归绿；Windows 侧 `go build` / `go vet` / 全部包测试代码交叉编译通过。
