# v10：三段统一成卡片，折叠箭头靠最右

对象：`dsh-ui-merged-v10.html`（在 v9 上改；v9 保留）

## 改了什么

**1. 去掉「小下标折叠样式」**
v9 里工作区行在 folder 图标下方挂了一个小三角，很突兀（你截图指的那处）。已删除：
- 工作区行只剩「folder + 名称」；
- 展开/收起改由**整行点击**完成（`aria-expanded` 仍在，读屏可感知），没有任何行内小箭头。

**2. 需要你 / 工作区 / 任务 统一成同一种卡片**
三段现在是同一个组件（`cardHeader()` + `.side-card` / `.card-hd` / `.card-body`）：

```
┌─────────────────────────────┐
│ ● 需要你  (5)            ⌄  │   ← 圆点 + 标题 + 计数 + 折叠箭头（最右）
├─────────────────────────────┤
│  待我处理 2                  │
│  ● …                        │
│  已完成未查看 3               │
│  ● …                        │
└─────────────────────────────┘
┌─────────────────────────────┐
│ ● 工作区  (7)  ⌕ ▽ ⊞     ⌄  │   ← 三个操作图标在箭头左侧
└─────────────────────────────┘
┌─────────────────────────────┐
│ ● 任务  (2)        +      ⌄  │
└─────────────────────────────┘
```

- 卡片：1px 边框、圆角 12、`surface` 底、段间距 8；头部 40 高，正文内边距 4/6。
- **折叠箭头统一放最右侧**（独立按钮，跟标题按钮是同一个 toggle 动作，点哪都行），展开/收起时图标在 `⌄ / ›` 之间切换。
- 标题 13.5px / 650；计数是小胶囊（需要你=琥珀、工作区=蓝、任务=灰，保留语义色，形状完全一致）。
- 正文里的行沿用 v9 照抄 dsh 的规格：32 高、圆角 10、内边距 `0 6px`、标题 14px、时间 12px；工作区行仍可整行点击展开。

## 为什么这么改（需求对齐）

- 「不要小下标折叠」→ 删掉行内三角，折叠只保留卡片头的箭头。
- 「三者统一」→ 同一套卡片结构、同一套头部布局、箭头同一位置；差异只在圆点/计数颜色（表示不同分区的语义）。
- 之前 需要你 是卡片、工作区/任务是裸列表，视觉上是三种不同东西；现在是一组同级分区。

## 验证

- 三段卡片头尺寸一致：40 高；三个箭头右端点全部落在 x=297（同一竖线）。
- 折叠：工作区展开 590 → 收起 42（只剩头 40 + 边框 2），再展开回 590；`aria-expanded` 同步 true/false。
- 行内不再有小三角：`.ws-row .chev` 计数 0。
- Lighthouse Accessibility 100、Best Practices 100；控制台 0 报错。
