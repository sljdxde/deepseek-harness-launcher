# v12：全 UI 一致性 review（字体 / 图标 / 对齐）

对象：`dsh-ui-merged-v12.html`（在 v11 上改）

## 一、审计怎么做的

把 8 个页面（会话 / 插件 / 插件管理 / 扩展 ×4 / 自动化 / 后台 / 设置）逐个渲染，遍历 `#rail #side #main #dock #statusbar` 下所有元素，统计：字号、字重、行高、圆角、图标尺寸、stroke-width，再扫硬编码颜色与 emoji。

## 三、字体：照 claude-web 的实现

读 `claude-web` 的 `tokens.css` 后照抄：

- `--font: 'Inter Variable','Inter',-apple-system,'Segoe UI Variable Text','Segoe UI',var(--font-cjk),system-ui,sans-serif`
- `--font-mono: 'JetBrains Mono Variable','JetBrains Mono','Cascadia Code','SF Mono',Menlo,Consolas,var(--font-cjk),monospace`
- `--font-cjk: "PingFang SC","Microsoft YaHei","Noto Sans CJK SC",sans-serif`
- 字号 token 对照：claude-web 的 `--fs-micro 11 / --fs-meta 12 / --fs-sm 13 / --fs-base 14`，落到我们的 **10/11/12/13/14/20**。
- **会话行标题回到 13px**（claude-web 的 `--fs-sm`，侧栏会话行就用它）——这就是你说「会话那里字体偏大」的那处，之前按 dsh 用了 14。

## 四、对齐：所有侧栏统一到一条线

根因：插件 / 扩展 / 设置 / 自动化 / 后台 这五个侧栏还在用旧的 `.chat-row` 网格（标题被 `1fr auto` 推到右边、`.sub` 掉到第二行），跟会话侧栏的新 `.row` 不是一套。

做法：五个侧栏全部改成和会话一致的 `side-card + card-body + row`（`.row-main` 装 lead+title，`.meta` 装时间 / 计数 / 箭头，动作绝对定位）。

## 六、仍存的已知项

- Inter / JetBrains Mono 走字体族声明，未内嵌 woff2；本机没装时回落到系统字体（外观接近，不是像素级一致）。要完全一致需把 claude-web 的 woff2 打进单文件（会让文件增大约 1-2MB），需要你点头。
- `.tag`/`.kbd` 等微型元素用 11px（claude-web 的 micro 也是 11），中文在极小胶囊里仍可能偏紧，已通过 150% 缩放检查无溢出。
