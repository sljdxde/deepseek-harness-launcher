# v13：换模型弹窗支持推理等级

对象：`dsh-ui-merged-v13.html`（= v12 + 本改动；v12 文件已同步更新，内容与 v13 一致）

## 问题

「换模型」弹窗只有模型列表，没有推理等级；设置页那行写着「默认」，实际无处可选。输入框那行的「深入」是个开/关，语义和展示都对不上。

## 做法

在弹窗里模型列表下面加一段 **推理等级**：

- 三段 `快速 / 标准 / 深度`，用项目里既有的 `.seg` 分段控件（`role=radiogroup` + `role=radio` + `aria-checked`），右侧实时显示当前值。
- 每档带 `title`：约 1 倍 / 约 1.5 倍 / 约 2-3 倍 token。
- 下方一行提示随所选模型变化：
  - V3.2：「深度会多跑几轮工具，回答更稳但更慢。」
  - mini：「建议用快速或标准，深度收益不大。」
  - R1：「自带长推理；这里只调预算上限。」
- 选模型时弹窗**不关**，可以顺手把等级一起定好；「在用」标记、勾选图标同步移动。
- 输入框那行的 `深入` 改成 `推理 · 标准/深度`，点它直接开这个弹窗；选「深度」等价于原来的深入开（`deep` 跟着走）。
- 设置 → 模型 → 推理等级，改成显示当前值。

## 修掉的一个真 bug

弹窗原先只在**弹窗种类变化**时重建（`dlg.dataset.key !== key`），所以弹窗内的状态（选模型、选等级）刷新不出来——点了没反应。给 modelPick 的 key 加上 `模型|等级` 组成的状态签名，弹窗内选完立刻重绘。

## 验证

- 打开弹窗：三段显示「标准」选中，右值 标准。
- 点「深度」：`aria-checked` 变为 深度、右侧值 深度、提示文案变、输入框 pill 变 `推理 · 深度`、`deep=true`；弹窗保持打开。
- 切到 mini：在用标记移动，提示变成 mini 文案，弹窗不关。
- Lighthouse Accessibility 100、Best Practices 100；控制台 0 报错。
