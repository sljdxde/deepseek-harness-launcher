# v14：模型设置照 dsh 的条目面板重做

对象：`dsh-ui-merged-v14.html`（在 v13 上改）

## 参考的样子（dsh 实拍）

```
┌────────────────────────────────────────────┐
│ 模型    deepseek 爽用 · routing group    › │
│ 推理等级                          Default › │   ← 悬停整行高亮（圆角）
│ 启用智能体团队协作  ⓘ              [ ○]  │
└────────────────────────────────────────────┘
```

## 做法

设置 → 模型，原来是四行「标签 + 说明 + 值」的表格，改成 dsh 的**条目面板**：

- 一个 4px 内边距的卡片，里面三条 44px 的条目，圆角 10，悬停/聚焦整行 `hover2` 高亮（跟 dsh 那张图的「推理等级」被选中态一致）。
- **模型**：左「模型」，右侧值 `deepseek v3.2 · routing group` + 右箭头，点开换模型弹窗。
- **推理等级**：左标签，右侧 `Default`（= 标准档，其它档显示 快速 / 深度），点开推理等级弹窗，三个选项带说明和 token 倍数，选完即时回写这一行。
- **启用智能体团队协作**：左标签 + `?` 说明图标（title 提示），右侧 38×22 开关（`role="switch"` + `aria-checked`，开=accent 实心、关=灰底），切换有 toast。
- 原来的「子代理模型 / 上下文压缩」挪到下面单独的「其他」卡片，不丢信息。

## 验证

- 三条目高度 44；模型值、推理等级值、开关状态都读自状态。
- 点「推理等级」→ 弹窗标题「推理等级」，三选项；选「深度」后弹窗关闭、行内值变「深度」、输入框 pill 同步 `推理 · 深度`。
- 开关：点击后 `aria-checked` true、变 accent 色；再点回 false。
- Lighthouse Accessibility 100、Best Practices 100；控制台 0 报错。
