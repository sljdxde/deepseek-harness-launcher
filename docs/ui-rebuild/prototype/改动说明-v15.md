# v15：换模型弹窗改成 dsh 的条目面板（这次改的是弹窗本身）

对象：`dsh-ui-merged-v15.html`

## 上一轮错在哪

v14 只把**设置 → 模型**改成了 dsh 的条目面板，但你说的是**换模型弹窗**（从输入框那把「推理 · 标准」点开的那个）。弹窗里还是「推理等级」标题 + 分段控件，所以看起来「没改」。

## 这次的做法

换模型弹窗重构成 dsh 的两级条目面板：

```
换模型
 ✓ DeepSeek V3.2  默认：长上下文、工具调得稳      在用
   DeepSeek V3.2 mini  便宜、快，适合小事
   DeepSeek R1  想久一点再答
 ─────────────────────────────────────────────
 推理等级                                  Default ›
 启用智能体团队协作  ⓘ                     [ ○ ]
 深度会多跑几轮工具，回答更稳但更慢。
```

- **删掉分段控件**（`.dlg .seg` 在弹窗里为 0 个），改成 dsh 的 `drow` 行：左标签、右侧值 `Default / 快速 / 深度`、末尾箭头。
- 点「推理等级」行**就地展开**三个子行（快速 / 标准 / 深度，各带「约 N 倍 token」说明与勾选），选完自动收起、行值更新、弹窗不关——就是 dsh 那种「行 → 子列表」的两级结构。
- 未选中的模型行去掉那个奇怪的图标，改留 16px 空槽，标题与选中行严格对齐。
- 弹窗底部补上 **启用智能体团队协作** 行（? 说明 + `role=switch` 开关），与设置页一致。
- 提示文案随模型变化（V3.2 / mini / R1 三套）。

## 验证

- 弹窗内 `.seg` 数量 = 0；`drow` = 推理等级 + 团队协作两行。
- 展开后三个子行可选，选「深度」→ 行值变深度、子列表收起、弹窗保持打开、输入框 pill 同步 `推理 · 深度`。
- 开关 `aria-checked` 与视觉同步；Lighthouse Accessibility 100、Best Practices 100；控制台 0 报错。
