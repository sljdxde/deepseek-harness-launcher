# v16：对话框的模型选择改成 dsh 那种轻量浮层

对象：`dsh-ui-merged-v16.html`

## 问题

输入框那行点模型会弹出整块「换模型」对话框，太重。dsh 的做法是**贴着输入框浮出一个小面板**，选完就走，不遮整屏。

## 做法

**输入框右下角**（原来放「model pill」的位置）改成一串轻量触发：

```
deepseek v3.2   Default  ⌄
```

- 点模型名 → 上方浮出**模型面板**：顶部搜索框「搜索模型…」，下面按组列（`DeepSeek` / `路由组`），当前项右侧打勾。选中即关闭。
- 点 `Default` → 浮出**推理等级面板**：`Default / Low / High / Max`，当前项打勾，选中即关闭。
- 点 `⌄` → 同模型面板。
- 浮层：`position:fixed` 贴着触发按钮上方（右边对齐、不出屏），`min 240 / max 360`，圆角 12、带阴影、`max-height 56vh` 可滚。
- 关闭：点浮层外、按 Esc、选中任一项；切换页面时如果触发按钮不存在也会自动收起。
- 等级统一成 dsh 的 **Default / Low / High / Max**（原「快速/标准/深度」改名），`deep` 在 High/Max 时为真；设置页与「换模型」对话框里的文案同步改成这四档。
- 输入框那行的「推理 · 标准」pill 已删除（不再需要），只保留权限、宿主保留区、子代理三个 pill。

## 验证

- 模型浮层：搜索框 + 两个分组 + 4 个条目 + 当前项勾选；选中后 `S.model` 变、浮层关。
- 等级浮层：4 项，选 High 后 `S.reason=High`、`deep=true`、footer 显示 High、浮层关。
- 点外部/按 Esc 均关闭；切页自动收起。
- Lighthouse Accessibility 100、Best Practices 100（修了 chevron 18px 点击区过小，改 24px）；控制台 0 报错。
