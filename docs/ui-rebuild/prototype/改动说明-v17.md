# v17：模型选择挪到输入框右下角

对象：`dsh-ui-merged-v17.html`

## 问题

v16 把模型/等级浮层的触发放在了目录 pill 后面（靠左），和 dsh 的「右下角」不一致。

## 做法

`.cm-row` 里目录 pill 之后加弹性空隙，把右侧整组推到最右，顺序照 dsh：

```
+  │  dsh-launcher · dsh-launcher [需审批]      ……      ⌘↵ 发送 18%   deepseek v3.2  Default  ⌄   ↑
```

- 模型名、等级、箭头落在**发送按钮左侧的最后一段**（实测：send 右端 x=1191，模型段 984-1155，紧贴 send）。
- 「⌘↵ 发送 18%」提示移到模型段左边，仍靠右但不抢位置。
- 模型/等级浮层仍贴着这三个按钮向上弹出，位置按触发按钮实时算，所以挪位置后浮层自动跟着。

## 验证

- 布局实测：`grow` 占 249px，cm-meta 70，cm-modelwrap 171，send 30，send 右端 = 行右端。
- 浮层仍从右下按钮向上弹出，选完即关。
- Lighthouse Accessibility 100、Best Practices 100；控制台 0 报错。
