# v18：背景加层（参考 claude-web 的壳/板与质感）

对象：`dsh-ui-merged-v18.html`

## 参考了什么

把 claude-web 源码拉到本地（`/tmp/claude-web-ref`）读了两处：

- `web/src/styles.css`：`.app{background:var(--surface-1)}` 是**壳**、`.sidebar{background:transparent}`、`.rpanel/.pane{background:var(--surface-0); border-radius:var(--r-card); box-shadow:var(--elev-1)}` 是浮在壳上的**板**；`--shell-gap` 让板与壳之间留出边。
- `docs/superpowers/specs/2026-10-16-texture-design.md`：发丝边（1px，2x 下 0.5px 并把边线强度乘 1.4）、暗色内高光环、双层接触阴影、圆角收敛。

## 做法

**1. 壳 / 板分层（这是背景变「多」的主因）**
- 侧栏、主区、右栏从「整屏铺满」改成**浮在壳上的三张卡片**：`border-radius:14px` + 1px 发丝边 + `--card-shadow`（接触阴影 + 大范围淡阴影），四周留 8px 壳边距。
- 三张卡背景用轻微竖向渐变（`--panel → panel 混一点 bg`），上亮下暗，读起来是一块被照亮的板。
- 状态栏去掉上边框、改为透明，直接坐在壳上。

**2. 壳层柔光**
`body::before` 三层大半径 `radial-gradient`：左上暖光、右上冷光、底部青色微光；日夜两套各自的强度（浅色 0.28/0.17/0.13，深色 0.22/0.13/0.11）。

**3. 细颗粒**
`body::after` 用**纯 CSS 点状噪点**（两层 0.5px 的 radial-gradient，3px 网格错位），`mix-blend-mode:soft-light`，浅色 .24 / 深色 .28。
> 踩坑：最初用 SVG `feTurbulence` 的 data URI 做颗粒，Chrome 解析这份内联 SVG 时把整张样式表截断（只剩 10 条规则、页面裸奔）。改成纯 CSS 点阵后恢复（720 条规则）。

**4. 内容区点阵**
`.thread-wrap::before` 22px 点阵（`--dot` 4%-9% 前景色），从上往下渐隐遮罩，只在对话区露一点纹理，不干扰正文。

**5. 卡片轻微浮起**
全局 `.card` 加 `--card-shadow`（浅色暖阴影 / 深色更沉），设置页、插件卡等一并受益。

## 验证

- 样式表规则数 720（改前 v17 正常；data URI 版只剩 10 条 → 已修）。
- 浅色 / 深色截图：`v18-light.jpg`、`v18-dark.jpg`；设置页：`v18-settings.jpg`。
- Lighthouse Accessibility 100、Best Practices 100（文字色未动，颗粒在所有内容之下，不参与对比度）。
- 控制台 0 报错。

## 已知项

- 1100px 窄窗且右栏展开时，主区只剩 ~390px，顶栏面包屑会被裁（v17 同样，属右栏最小宽度问题，不是本次引入）。需要的话下一步可以把右栏的自动收起阈值从 980 提到 1200。
- 颗粒是 CSS 点阵近似，不是真随机噪点；如需更细腻可换成打包的 32×32 PNG 噪点贴图（体积 +1KB）。
