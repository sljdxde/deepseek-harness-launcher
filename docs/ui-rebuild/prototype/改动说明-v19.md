# v19：把背景「做实」（上一版太淡，看不出变化）

对象：`dsh-ui-merged-v19.html`

## 为什么上一版看不出变化

v18 的壳色 `--bg:#f4f1e9` 和面板色 `--panel:#faf8f3` 只差一点点，壳边只有 8px，柔光又是低透明度——叠在一起等于没变。根因是**壳与板的明度差太小**。

## 这次改的

1. **壳色独立成 token，并明显压深**
   - 浅色：壳 `#e7dfcc` / 轨道 `#efe8d8`（原来是 `#f4f1e9`，几乎与面板同色）
   - 深色：壳 `#0b0c0e` / 轨道 `#101114`（原 `#121316`）
   - 面板保持 `#faf8f3` / `#17191e` → 壳与板拉开一个明度档，卡片"浮起来"看得见。
2. **壳边距 8 → 14，圆角 14 → 16**，帧更明显。
3. **柔光加强**：浅色暖光 .28→.34、深色 .22→.26；底色变深后光晕才有对比。
4. **颗粒加强**：浅 .24→.38、深 .28→.42。
5. **对话区点阵加强**：20px 网格、不透明度 .85，遮罩更实。

## 窄窗兜底（新增）

`@media (max-width:1280px)`：侧栏/主区/右栏退回满铺（去边距、去圆角、去阴影），避免 14px 壳边距把主区挤到 ~390px 时卡片被裁。1500px 及以上是完整的卡片布局。

## 验证

- 1500×920 浅色/深色截图：壳与板明度差清楚，三张卡浮起；`v19-light.jpg`、`v19-dark.jpg`。
- 1100px 窄窗：卡片退满铺，无裁切（顶栏面包屑在右栏展开时仍会紧，属旧问题）。
- Lighthouse Accessibility 100、Best Practices 100；控制台 0 报错。
