# v20：背景底纹主题 + 对话区水印 + 时段色温

对象：`dsh-ui-merged-v20.html`

## 1. 壳上 4 种可切换底纹（外观 → 背景底纹）

设置 → 常用 → 外观 新增一行「背景底纹」：**纸纹 / 网格 / 点阵 / 纯色**，分段按钮即时切换。

- 实现：`html[data-bg="..."]` 决定 `.app::before` 的 `background-image`（固定层、在卡片之下，纯 CSS 渐变，无图片请求）。
  - `paper` 纸纹：横向 1px 细纹 + 90px 竖纹（模拟纸纤维）
  - `grid` 网格：28px 正交 1px 线
  - `dots` 点阵：20px 圆点
  - `plain` 纯色：无纹理
- 墨色用 token `--pat-ink`（浅 `rgba(27,28,25,.10)` / 深 `rgba(255,255,255,.07)`），只在壳的边距与卡片间隙可见。

## 2. 对话区极淡大号几何水印

`.thread-wrap::after`：以右上角为圆心的 **92px 同心圆 + 30° 斜线**，`opacity .55`，向下 62% 渐隐。
颜色 token `--wm`（浅蓝 11% / 深蓝 10%），远看是纹理、近看不抢字。

## 3. 背景色随时段微变

`applyBg()` 按当前小时在 6 档色温里选一层 `linear-gradient(180deg, var(--time-tint), transparent 55%)` 叠在壳层最上：

| 时段 | 浅色 | 深色 |
|---|---|---|
| 清晨 5-9 | 暖橙 14% | 蓝 10% |
| 上午 9-12 | 暖黄 10% | 暖棕 8% |
| 正午 12-14 | 近白 5% | 米白 5% |
| 下午 14-18 | 暖沙 10% | 暖棕 8% |
| 傍晚 18-21 | 橙红 14% | 橙棕 12% |
| 夜间 21-5 | 冷蓝 10% | 深蓝 14% |

外观里「色温随时段」一行显示当前时段（清晨/上午/正午/下午/傍晚/夜间），切主题或改底纹时自动重算。

## 验证

- 底纹切换：`data-bg` 与 `.app::before` 的 `background-image` 四种值实测正确（paper 横纹 / grid 正交线 / dots 圆点 / plain none）。
- 水印：`::after` 的 `repeating-radial-gradient + repeating-linear-gradient` 生效，opacity .55。
- 色温：当前 17 点取「下午」暖沙色，`--time-tint = rgba(250,205,150,.10)`。
