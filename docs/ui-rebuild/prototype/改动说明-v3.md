# 融合版原型 v3：改了什么

对象：`dsh-ui-merged-v3.html`（原件 `dsh-ui-merged.html` 同目录，保持不动）。

## 1. 布局（「按钮点不动」的真因）

- `.main` 从 3 行网格改为 4 行：`auto auto minmax(0,1fr) auto`，并给 `.topbar / .tabs / .thread-wrap / .composer / .page` 显式分配行。
- 效果：聊天页 6 个 tab 从 1px 恢复到 40px，`elementFromPoint` 命中 `BUTTON.tab`；实测网格行 `46 / 40 / 563 / 149`。
- 普通页（设置、插件等）的 `.page` 跨 2–4 行；带 tab 的页（轨迹/上下文/编队/统计）`.tabs + .page` 固定在第 3 行，不与 tab 重叠。

## 2. 交互补齐

| 控件 | 改前 | 改后 |
|---|---|---|
| 顶栏「分屏」/ ⌘D | 只换标签，无布局 | 真 2 栏：左对话 + 右轨迹；再点退出；开分屏自动切回对话 |
| 消息「复制」 | 只 toast | `navigator.clipboard`，失败回落 `execCommand('copy')`，按本轮正文复制 |
| 自动化启停 | 只 toast，文案不变 | 真改 `AUTOS[].on`，按钮文案跟着变 |
| 右栏「全部暂存」 | 只 toast | 给每块 diff 打 `staged`，卡片显示「已暂存」 |
| 「提交…」 | 清空全部 diff | 只提交已暂存的，未暂存保留；没暂存时提示 |
| 「还原」 | 清空 | 不变（清空即还原） |

## 3. 假开关处置

- 所有仍是 `data-act="toast"` 的控件（导入、检查更新、SSH 测试、加目录等）统一加 `.is-stub`：透明度 0.55、`cursor:help`、`title="演示占位：…"`。
- 原则：**要么真做，要么显式标成演示**，不再出现「点了只弹一句、看不出是假」的控件。

## 4. 可达性

- `.pin` 增加 `.chat-row:focus-within` 显形；`@media (hover:none)` 下 `.pin`、`.ws-row .more`、`.msg-acts` 常显，触屏与键盘可达。

## 5. 验证

- 浏览器实测（file://）：网格行 46/40.4/563/149；轨迹页 page 563 不压 composer；分屏 2 pane；暂存后 3 个「已暂存」；提交后 diff 清空并显示「都提交了」；自动化按钮「已启用 → 已停用」；控制台 0 报错。
