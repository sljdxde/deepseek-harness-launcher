## C 组（工作区/目录）

- **C3 白名单标记**：目录不在 `~/Pod`、`~/Pod/tasks` 内时，目录行与输入框目录 pill 都标「需审批」，选中时提示「首次执行会问你」。
- **C4 删除工作区**：从「管理目录」里删除工作区时，会话不丢，统一移到「未分组」。
- C1/C2 是规格层约定（优先复用宿主数据、三处文案同源），原型保持现状，进规格由 09 收口。

## D 组

- **D1**：插件页保持「融合版详情页」形态；三段容器作为插件自绘时的可选退化，原型不展开。
