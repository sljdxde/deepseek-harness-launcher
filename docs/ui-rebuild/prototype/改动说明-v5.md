# 融合版原型 v5：六条修订

对象：`dsh-ui-merged-v5.html`（在 v4 上改；v4 的确认项全部保留）。

## 1. 目录选择器：加目录生效 + 关闭键固定

- 「加目录」以前空输入时只在底部弹一句、几乎看不见 → 现在输入框下方有**红色内联提示**（「这里要填绝对路径」「路径要以 / 开头」），合法路径会真的写进工作区并选中。
- 关闭 X 改为**绝对定位在对话框右上角**，标题再长也不移动。
- 「管理工作区」里的解绑/添加也接真状态，不再是 toast 占位；最后一个目录禁止解绑。

## 2. 权限范围与 dsh 对齐

- 原来的「标准 / 自动批准安全命令 / 每步询问」换成 dsh 的三档：**仅可查看 / 工作区内修改 / 完全权限**，图标分别是眼睛 / 铅笔 / 告警三角。
- 输入框那颗 pill 跟着档位换图标与文案，默认「工作区内修改」；弹层里写明「档位决定能碰哪些文件，不等于什么时候问你」。

## 3. 品牌图标换成 dsh 的鲸标

- 从运行中的 dsh 页面取到官方 `FishLogo` 的 SVG path（viewBox 0 0 23.16 17.04）。
- 图标栏左上角、助手消息头像都换成鲸标；不再用四角星。

## 4. 插件侧栏：层级放大、插件带图标

- 「固定 / 更多 / 管理」三个层级标题放大到 13.5px/650，行高与留白一起加。
- 每个插件行改成：**图标 + 名称 + 版本 + 图钉**，固定区与「更多」都带图标，不再只有文字。

## 5. 插件管理页换成最新设计

- 结构照 dsh 插件管理：左栏 **发现 / 内置 / 已安装 / 插件源**，右侧内容区。
- 发现页：搜索 + 分类 chips（全部/界面/会话/工具/自动化/数据）+ 本周推荐 + 8 张卡片（图标块、名称、作者、两行摘要、星标/下载/版本、安装按钮）。
- 已安装：8 行，图标 + 版本 + 启停按钮；内置：6 个核心组件；插件源：2 个源 + 说明。
- 字体、圆角、底色全部走原型 token（暖纸底、10-14 圆角、12-13px 正文），不搬宿主的 `--dsw-*`。

## 6. 会话侧栏拆成三段

1. **需要你**：保持可折叠，默认展开。
2. **工作区**：以目录为层级，一个目录一个工作区；整段可折叠，每个工作区也可单独折叠；顶部保留 dsh 的三个功能键（搜索 / 筛选 / 新建工作区），搜索能同时匹配工作区名与会话名，筛选可只看有会话的。
3. **任务**：临时会话，不绑目录；「+ 新建任务」直接进不绑目录的空态，写完第一句就建一个临时会话。

## 验证

- 浏览器实测：加目录 1 → 2 个目录、弹层关闭；X 计算样式 `position: absolute`；权限弹层三项与 dsh 一致；鲸标 viewBox 正确；插件侧栏 3 行全带图标；插件管理 4 tab / 8 卡 / 6 分类，筛选「工具」剩 2 张；会话侧栏 7 个工作区 + 2 个任务；控制台 0 报错。
