# 融合版原型 v6：图标栏 / 插件管理 / 工作区层级

对象：`dsh-ui-merged-v6.html`（在 v5 上改）。

## 1. 图标栏收起后点鲸标能展开

- 鲸标从「导航到会话」改成 `railHome`：宽屏下侧栏是 `noside` 就展开，否则回会话；窄窗下切换抽屉。
- 实测：收起后点鲸标，`noside` 从 true → false。

## 2. 插件管理补全

- **排序**：推荐 / 下载最多 / 星标最多（按真实数值排序，`12k` 参与比较）。
- **AI 搜索**：独立入口 + 描述式输入 + 「找」；提示写明原型按关键词模拟，不把整份索引交给模型。
- **分类补全**：全部 / 界面 / 会话 / 工具 / 自动化 / 数据 / 其他，数据加到 12 个样本。
- **安装 / 卸载**：未装显示「安装」，已装显示「卸载」；卸载后从已安装列表移除，侧栏同步隐藏。
- **启停按钮**：已安装与内置都改成原型的分段按钮（启用 / 停用），内置组件也能停用。
- 已安装行加「卸载」危险按钮；内置页说明「不能卸载但可停用」。

## 3. 工作区 / 会话层级重做

- **删掉**「在这个工作区新建会话」「新建任务」两个大虚线按钮。
- 工作区行：悬停出现 `+`（在该工作区新建会话）与 `…`（菜单）；`…` 菜单 = 重命名工作区 / 在 Finder 中显示 / 新建会话 / 删除工作区。
- 会话行：悬停出现 置顶 / 归档 / `…`；`…` 菜单 = 置顶会话 / 重命名 ⌘G / 分叉会话 ⇧⌘F / 复制 Session ID / 归档会话 ⌘A / 删除会话。
- 右键菜单浮层带快捷键提示与分隔线；点外部或 Esc 关闭；删除类操作先弹确认。
- 归档会话从列表移除；删除工作区时会话移到「任务」，不丢。
- 任务段只保留标题栏的 `+`，不放大按钮；空态文案改为「点右上 + 新建」。

## 验证

- 控制台 0 报错。
- 收起侧栏 → 点鲸标 → 展开；工作区行有 `+`/`…`；大按钮数量 0。
- 插件管理：3 个排序、7 个分类、12 张卡、AI 输入、已安装 8 行带分段启停 + 卸载、内置 6 行可停用；卸载后已安装 8→7。
- 会话菜单 6 项、工作区菜单 4 项；删除/改名确认弹层可开。
