## P0 修改

1. **模态改原生 `<dialog>` + `showModal()`**
   - 全部 14 个弹层（选目录、权限、模型、附件、工作区、重命名、删除确认、总览、回退说明、帮助…）都换成原生 dialog；`closedby="any"` 支持点遮罩关闭，另按指南补了 Safari 的 pointerdown/pointerup 兜底。
   - 删掉了 `role="dialog"`、自建 scrim、自建的 Esc/点遮罩逻辑；背景 inert、焦点陷阱、`::backdrop`、关闭后回焦都由浏览器提供。
   - 滚动穿透用 `dialog:modal{overscroll-behavior:contain}` + `dialog::backdrop{overflow:hidden;overscroll-behavior:contain}`，没有给 html/body 加 `overflow:hidden`。
   - 命令面板（⌘K）按「页面仍可操作」的原则用 `<dialog popover="manual">`，不是 showModal。
2. **右键菜单改 Popover**
   - `div[role=menu]` → `popover="auto"` + `role="menu"` + `menuitem` 按钮；点外部/Esc 由浏览器 light-dismiss；打开时把焦点移到第一项，支持 ↑↓ / Home / End。
   - 位置仍用指针坐标（浏览器不给右键位置语义），但已按面板实际宽高做视口内夹取。
3. **对比度**
   - `--ink4` 浅色 `#928f84 → #67645a`、深色 `#767469 → #9a978c`：小字在 panel/bg/surface2/选中行底色上都 ≥4.5（实测浅 5.58、深 6.01）。
   - `--amber` 浅色 `#96601a → #7a4d12`、深色 `#e0a76a → #f0bd85`，修 `.chip.demo` 暗色 3.53。
   - `.is-stub` 不再用 `opacity:.55`（会把文字压到 2.5），改成虚线边框 + 弱化底色。
   - 选中会话行底色由 `surface3`（太深）改 `accent-soft`。
4. **目标尺寸**：`.icon-btn.xs`、`.pin` 都从 20×20 提到 24×24；顶部 chip 设 `flex:0 0 auto` 并在 ≤1600 只留图标，避免被挤成 13.9px。
5. **交互语义**
   - 会话行/工作区行/插件行全部拆成「主按钮 + 兄弟操作按钮」，不再有 button 内嵌 role=button。
   - 分段控件（启用/停用）、排序、分类 chips 补 `aria-pressed`；工作区行补 `aria-expanded`；插件图钉补 `aria-pressed`。
   - 图标栏 `aria-label` 带角标数字（「插件，3 个待办」），修 label-content-name-mismatch。
   - 会话标签页改 `role="tablist"` + `role="tab"` + `aria-selected`，并支持 ←/→/Home/End。

## P1 修改

6. `<search>` 包住工作区搜索与插件搜索（`pm-search`/`sec-search`）。
7. 标题层级：聊天页补视觉隐藏 h1（会话标题）；卡片标题从 h4 改为 h2（不再跳级）；弹层标题统一 h2。
8. 暗色：补 `<meta name="color-scheme" content="light dark">`，并在两套主题上分别声明 `color-scheme: light/dark`，原生滚动条/表单控件/画布跟随主题。
9. 滚动条：改用 `scrollbar-width:thin` + `scrollbar-color`（`light-dark` 由主题 token 提供），不再只依赖 `::-webkit-scrollbar`。
10. 跳转链接：「跳到主内容」在键盘聚焦时出现。

## 未做（有意）

- **折叠区改 `<details>`**：与「整块 innerHTML 重绘」的架构冲突（重绘会把 details 的 open 状态重置）；改成 details 需要同时换渲染方式，留到真机实现（React/插件层）时一起做。
- **CSS Anchor Positioning 定位菜单**：右键菜单没有触发元素，需要占位锚点；当前用坐标 + 视口夹取已满足可用性，锚点定位留到正式实现。
- SEO / agentic（meta description、robots.txt、llms.txt、ard.json）对本地桌面应用无意义，未加。
