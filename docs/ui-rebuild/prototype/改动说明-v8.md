# v8：侧栏重做（对齐 dsh 当前设计）

对象：`dsh-ui-merged-v8.html`（在 v7 上改；v7 保留）

## 问题 → 做法

| 反馈 | 根因 | 做法 |
|---|---|---|
| 点会话名会「跳」 | ① 每次点击整块 `innerHTML` 重绘，滚动位置被重置；② 行高不固定（标题+时间+diff 堆成多行）；③ 悬停动作插进 flex 流里，宽度一变文字就挪 | ① `renderSide()` 保存/恢复 `scrollTop`，并按 `data-act`+`data-id` 还原焦点；② 所有行固定 **32px**（与 dsh 一致）；③ 动作改成 `position:absolute` 覆盖在右侧，悬停时把时间淡出——几何不变，所以不跳 |
| 层级看不出来 | 工作区/会话/任务平铺，只靠缩进 | 三段结构 + 明确层级：工作区行（caret+folder，500 字重）→ 子会话缩进 32px 并带 1px 竖向引导线；会话字号降一档、颜色降一档 |
| 「需要你」定位不清 | 原先是「需要你」+另起一排状态芯片 | 汇总成一张卡：**待我处理 N** + **已完成未查看 M**，两组分栏、各带计数，项目前用琥珀/绿色状态点；顶栏总数是两者之和 |
| 任务段同样跳 | 同上 | 同一条 `.row` 组件，统一 32px |
| 排版/留空乱 | 间距不统一 | 对齐 dsh 的尺度：行 32、行内边距 `0 8px 0 9px`、圆角 12；分区间距 10px，行间距 1px；区头 32px、行内动作 26px；title 13px / meta 11px 等宽 |

## 具体规格（照 dsh 实测）

从运行中的 dsh 侧栏量得并复刻：
- 会话行 32px、`padding:0 8px 0 9px`、`border-radius:12px`；
- 悬停动作 `rowActions` 宽 0（绝对定位），不参与布局；
- 工作区行 32px、`gap:6px`、同样的 12 圆角；区头 36px、`padding-left:12px`、`gap:4px`，颜色 `#81858c`；
- 图标 14px。

## 结构

```
需要你 (5)                     ← 卡片，可折叠
  待我处理 (2)                 ← 琥珀点
  已完成未查看 (3)              ← 绿点
工作区 (7)  [搜索][筛选][新建]   ← 区头
  ▾ 📁 dsh-launcher (4)

      融合版：现有 + 工作台  3 分钟   ← 当前选中
  ▸ 📁 dsh-bot (2)
任务 (2)  [+]                  ← 临时会话，不绑目录
  整理这周的周报           12 分钟
```

## 可访问性

- 每段用 `<section aria-label>`，区头按钮带 `aria-expanded`；行内只有「主按钮 + 兄弟操作按钮」，没有嵌套交互。
- 动作按钮有 `aria-label`，并在 24×24 以上；纯图标按钮用视觉隐藏文字补名称。
- Lighthouse：Accessibility **100**、Best Practices 100 保持。

## 验证

- 固定行高 32、区头 32；点击会话后 `scrollTop` 120 → 120，行 top 289 → 289，宽高不变（无跳动）；悬停前后行几何一致。
- 浅色/深色截图：`v8-sidebar-light.jpg`、`v8-sidebar-dark.jpg`；插件页侧栏未受影响：`v8-sidebar-plugins.jpg`。
- 控制台 0 报错。

## 未做

- 工作区目录层（一个工作区挂多个目录）仍只在「管理工作区」里管理，侧栏按 dsh 的做法只展示工作区一行 + 会话。
