## 删掉的「自我创造」

- 工作区行右侧的会话计数（dsh 没有）
- 常显的折叠箭头（dsh 只有 hover 时出现三角）
- 子会话缩进 32px + 竖引导线（dsh 会话与工作区标题同一 x）
- 会话行左侧的消息图标（dsh 是 16px 空槽）
- 工作区标题的 550 字重（dsh 用 400，靠 folder 图标区分层级）

## 排版对齐

- 需要你卡片里的两组条目重新对齐到同一网格：`padding-left 9 + 16 槽 + 6 gap`，实测所有条目圆点 x=79、标题 x=90（v8 截图里的错位是旧构建）。
- 区头与卡片头都对齐到 12px 起始线。
- 行距统一 4，组间距 8。

## 验证

- 实测：区头 36 / 文字 14px·600 / 按钮 28·8·gap4 / 行 32 / 行距 4 / 标题 14·400 / 时间 12 / 会话与工作区同 x / 动作 absolute right 8 gap 13 / 箭头默认 display:none。
- 动作顺序：会话 = 更多操作·归档会话·置顶会话；工作区 = 工作区操作·新建会话。
- Lighthouse Accessibility 100、Best Practices 100；控制台 0 报错。

## 仍与 dsh 的差异（有意保留）

- 「需要你」是原型新增的汇总卡（dsh 侧栏没有这块），沿用 dsh 的行规格与 12px 对齐线。
- 「任务」段是对不绑目录会话的归类（dsh 里这类会话混在「临时文件」等工作区里），沿用 dsh 的区头 + 行规格。
