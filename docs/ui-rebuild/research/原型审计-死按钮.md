# 融合版原型死按钮审计（研究：proto-audit）

对象：`dsh-ui-merged.html`（2091 行，原件）。结论：**问题在布局，不在事件绑定。**

## 1. 有控件、无处理（1 个）

| 控件 | 位置 | 证据 |
|---|---|---|
| 顶栏「分屏 / 退出分屏」 | 1022 | 62 个 case 里没有 `split`；⌘D 只改标签 +「(演示)」toast，布局从未实现 |

其余 133 处 `data-act` 都有对应 `case`（覆盖 79 个可见控件）。

## 2. 被遮挡 / 看不见

1. **聊天页 6 个 tab**：`.main{grid-template-rows:auto minmax(0,1fr) auto}`（161）只 3 行，聊天页却有 4 块（topbar / tabs / thread-wrap / composer），实测行高 `46/0/678.7/149.3`，`.tabs` 只剩 **1px**，407 的 `overflow-x:auto` 又把按钮裁掉；`elementFromPoint` 命中 topbar / thread，6 个 tab 全部点不到。
2. **hover-only 按钮**：`.msg-acts{opacity:0}`（324）、`.ws-row .more`（124）、`.pin`（136）——触屏与 Tab 都够不到。
3. 层本身没问题：`.layer{display:none}` / `.on{display:block}`，关层清空 innerHTML；toast `pointer-events:none`。

## 3. 只 toast / 假开关

- `copy`（1940）：提示复制了，但全文件没有 `clipboard`/`execCommand`。
- `toast` 共 16 处：运行明细、重试、更多视图、导入/检查更新、从文件夹/从 GitHub、Skill 启停、添加服务器、添加主机、测试连接/打开、新建、新建任务、解绑、添加目录、删除工作区、@ 它。
- `autoToggle`（1962）：只 toast，不改 `a.on`，按钮文案永远不变。
- `mcpProbe` / `mcpRestart` / `setJump` / `stage`：同上，只提示。
- `split`：见清单 1。

## 4. 事件委托

click 挂 `document`（1780），`render()` 重写 innerHTML 不影响；`stopPropagation` 只在单监听上；`disabled` 拦截与空输入禁用是真实限制。**无问题。**

## 最低成本修法

`.main` 改 4 行网格 + 给各块分配行；补 `case 'split'`；`copy` 接剪贴板；`autoToggle`/`stage` 改真实状态；其余 toast 控件统一标「演示占位」。
