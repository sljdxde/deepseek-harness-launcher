## 做了什么（本次已落地）

1. **`scripts/check-generated.mjs`**：扫全仓已跟踪文件的冲突标记；解析 `client.js` 的 `#region *-from-lib`，按大括号深度只取**顶层声明**查重名；校验 `BUILD_STAMP` 的版本前缀与近期 sha。退出码 0/1/3。
2. **`scripts/check-tests.mjs`**：禁止 `assert.match(SOURCE …)` / `SOURCE.match(` / `SOURCE.includes(` 等实现细节断言；只允许文件级 `// source-assert-allow-file: <理由>`（上限 8 处，运行时会逐文件列出放行清单）。
3. **`scripts/coverage-check.mjs`**：改为自动发现 `Plugins/*` 下带 test(s) 的插件并跑测试；任何"有 lib 代码却没有 TARGETS 条目"的插件直接失败（历史两个插件显式列入 `GRANDFATHERED` 并注明理由）。
4. 两者接进 **`scripts/test.sh`**（sync-contract 之后）与 **`.github/workflows/ci.yml` 的新 `guards` job**（`fetch-depth: 3`）。
5. 顺带把 3 个接线测试从源码断言改成「生成块与源一致 + 生成块内含符号」的行为断言；剩余 6 个文件的源码断言只用于 **region 标记切块** 与 **旧符号消失** 两类不变量，已逐个标注理由。

## 已知边界
