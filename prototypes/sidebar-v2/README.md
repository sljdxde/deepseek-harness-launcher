# 侧栏改造原型（v2）

> **决策（2026-11-11）：采用 C 自由积木。** 实施与兼容方案见 [docs/sidebar-deck-plan.md](../../docs/sidebar-deck-plan.md)；M0 接管机制已在隔离环境验证通过（`screenshots/spike-接管验证.jpg`）。

一次性 UI 原型，用来回答一个问题：**侧栏应该紧凑成什么样、最近会话怎么内置、区块怎么拖。**

- 打开方式：直接双击 `index.html`（无构建、无依赖），或 `open prototypes/sidebar-v2/index.html`
- 切换方案：底部工具条的 `‹ ›` / 键盘 `←` `→` / URL `?variant=A|B|C`
- 状态：只存在 `localStorage["dsh-proto-sidebar-v2"]`，底部「重置」清当前方案布局

## 三个方案

| | A 紧凑原生 | B 最近优先 | C 自由积木 |
|---|---|---|---|
| 信息结构 | 保留官方工作区树，只展开当前工作区 | 最近会话做主列表，工作区默认折叠 | 每个分区是一块积木 |
| 面板入口 | 两列网格 | 一行图标轨 | 两列网格 |
| 首屏信息量 | 中 | 最高（12 条最近会话 + 7 个工作区） | 中高 |
| 拖动 | 主栈排序 / 折叠 / 拖宽 | 主栈排序 / 折叠 | 主栈 ↔ 底部工具条 / 换边 / 拖宽 |
| 适合 | 想保持官方手感、只做减法 | 绝大多数时间在切最近会话 | 想要可自由编排的工作台 |

截图见 `screenshots/`。

## 已实现的可交互点（不是静态图）

- **区块拖动**：区块标题左侧的三道杠是把手；拖动时原位置留虚线占位，可跨区块排序；C 版还可以拖进底部工具条（压成一行入口，点开是浮层）。
- **折叠**：点区块标题或 `⋯` 菜单。
- **宽度**：拖侧栏右边缘（A/C）。
- **换边**：C 版顶部「靠右/靠左」。
- **移除内置最近会话**：`最近会话` 的 `⋯` → 移除；底部出现「已移除 · 恢复」。对应需求里的「内置但用户可卸载」。
- **B 版搜索**：输入即时过滤最近会话。
- 所有布局改动都会记住，刷新不丢（原型行为，正式实现应落到设置里）。

## 与真实站点的关系

- 尺寸/配色/图标取自当前正在运行的 DSH Web（侧栏 280px、行高 32/34px、底色 `#f9fafb`、品牌鲸鱼与官方图标 sprite 均来自线上 DOM），所以三版都能直接和现网对比。
- 主对话区是演示用的静态内容，不接真实会话。
- 现网侧栏现状（对照）：官方 `dsh-client-ui-sidebar` 渲染工作区树（project 34px / session 32px），底部 `最近会话` 来自第三方 `@yfwu2020/dsh-recent-sessions` 的浮层入口，`归档` / `插件管理` 由两个启动器插件各占一行 42px。

## 实现落点（选定方案后再做，不在本原型范围内）

1. **内置最近会话**：`Plugins/` 下新增 `DSHRecentSessions`，登记进 `Sources/main.swift` 的 `BundledPlugin` 列表，随 App 资源打包、由 `--patch` overlay 默认启用；`PluginIsolationSupport` 已支持按行禁用，所以「内置但可卸载」不需要新机制。
2. **紧凑侧栏**：官方侧栏没有「分区拖动」扩展点，两条路二选一：
   - 启动器内置一个接管左侧栏的外壳插件（参照 `tianxiaz/dsh-recent-sessions` 的做法：禁用官方侧栏包，在其中原样渲染官方工作区浏览区）；
   - 或先只做「紧凑 + 最近会话内置」，把拖动留到下一版（改动面小很多）。
3. 拖动排序 / 宽度 / 换边需要持久化到设置，而不是 localStorage。

> 原型是一次性的：验证完把选定方案重写进正式插件，不要直接搬这份代码。
