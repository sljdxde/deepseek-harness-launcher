# 侧栏排版原型 v3（参考 magpie）

按 `magpie/internal/gui` 的应用侧栏语言重做的 DSH 侧栏排版原型。一次性原型：无构建、无依赖，刷新即回默认状态。

打开：`open prototypes/sidebar-v3/index.html`

## 参考的设计语言（取自 magpie app.css）

- **一整块安静的表面**：`--bg #f4f4f6` 底、无卡片装饰；分组靠 11px 小标签 + 14px 上边距分隔
- **字号阶梯**：分组标签 11px/500/字距 .04em；子行 12.5px；面板主行 13px；meta 11px 等宽数字
- **行与圆角**：子行 26px / 6px 圆角；主行 30px / 7px 圆角；悬浮只换文字色（`--ctl` → `--ink`），选中才有 `6.5%` 墨色底
- **主按钮**：选中行/新会话用白卡 + 0.5px 描边 + 两层阴影（magpie 的 `--seg-edge`）
- **强调色克制**：只给运行中状态点和新会话发消息按钮，侧栏本身保持石墨色

## 这一版解决的四个问题

| 问题 | 做法 |
|---|---|
| 分组标题比目录名靠右 | 分组标题与行内容共用一个 10px 左参考线；标题在 18px，行文字在图标之后，标题永远最左 |
| 下方行太松 | 子行 26px、主行 30px；分组之间只有标签的 14px 上边距，没有额外卡片间距 |
| 收起最近会话后工作区不变高 | 工作区是唯一 `flex:1` 分组，收起最近会话后自动占满剩余高度（截图 02） |
| 面板 10 个怎么办 | 主行列表封顶 190px，内部滚动 + 底部渐隐，标签右侧显示总数（截图 03） |

## 交互

- 点分组标题收起/展开（最近会话收起时看工作区弹性）
- 底部工具条切「最近会话 展开/收起」「面板 4/10」
- 拖动把手只在插件实现里有，原型只验证排版
