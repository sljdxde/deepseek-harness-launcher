# 侧栏排版原型 v5 · 克制的四档字号

这版不再靠"再多调几个像素"，而是先立**约束**，再照约束写。

打开：`open prototypes/sidebar-v3/index.html` → v5 在 `prototypes/sidebar-v5/index.html`

## 排版纪律

字号只有四档，每档只有一个职责，全文件不允许出现第五个值：

| 档位 | 值 | 唯一职责 |
|---|---|---|
| L0 | 14px / 650 | 左上角品牌名 |
| L1 | 13px / 650 墨色 | 分组标题：最近会话 / 工作区 / 面板（右侧带发丝线） |
| L2 | 12px / 400 | 行文字：会话名 / 工作区名 / 面板名 |
| L3 | 11px / 500 浅灰 | 辅助信息：时间 / 计数 / 折叠说明（等宽数字） |

颜色同理只有三级：墨 `#16161a` / 中灰 `#4c4c54` / 浅灰 `#8c8c95`。
强调色只留给「运行中」状态点，别的地方一律石墨色。

## 结构

- 三个分组共用一套语言：**发丝线标题 + 扁平列表**，行高 25px（面板主行 28px）
- 分组标题永远是最左，行内容从图标之后开始（标题 0px，行文字 26-42px）
- 工作区是唯一 `flex:1` 的分组：收起最近会话它立刻占满剩余高度
- 面板 = 扁平列表 + 发丝分隔行（不再有白卡）；默认只显 4 个，其余折叠成一行「显示其余 N 个」
- 标题右侧的漏斗图标打开「管理面板」浮层，逐个开关控制哪些面板出现在侧栏

## 修掉的具体问题

- 面板图标被通用 `span` 选择器撑成 114px（插件管理/归档管理那两根黑条）→ 标签改用独立类名，选择器只命中自己的元素
- flex 子项默认会被压缩 → 所有行加 `flex:none`，否则面板行被挤成 21px
- 底部渐隐遮罩会把「机架感知功能」这类文字切一半 → 去掉遮罩，改细滚动条
- 面板展开时把工作区挤到最小 → 面板列表内部滚动（封顶 26vh），不外溢
