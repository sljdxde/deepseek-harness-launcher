# 侧栏排版原型 v6 · 更醒目的分组标题 + 精炼面板区

v5（克制的四档字号）的遗留问题：三个分组标题只有 13px/650，在满屏小字里几乎扫不出来；面板区虽然扁平，但选中态靠「加粗文字」表达，和侧栏其它部分撞气质。

打开：`open prototypes/sidebar-v6/index.html`

## 这一版改了什么

| 问题 | 做法 |
|---|---|
| 最近会话 / 工作区 / 面板三个标题不够醒目 | L1 档 13px/650 → **14px/700**，行高 26→30px，区块间距 14→16px。它是侧栏里唯一的大字（L0 只给品牌名） |
| 面板区看着散 | 行高 28→29px、圆角 7px、图标 15px 间距 9px；发丝分隔线内缩到 10px 两侧对齐 |
| 选中态靠加粗字，和会话行的粗体混 | 改成**浅墨底 + 左侧 2px 竖条**，不加粗文字 |
| 「显示其余 N 个」像一截断线 | 改成居中胶囊（浅底 + 圆角），悬停变深 |
| 管理面板只能一个个点 | 浮层头部加**全部隐藏 / 全部显示**两个快捷动作 |

## 保留的约束

- 字号仍然只有四档：L0 15（品牌）/ **L1 14/700（分组标题）** / L2 12（行文字）/ L3 11（辅助信息）；
- 颜色只有三级：墨 `#16161a` / 中灰 `#4c4c54` / 浅灰 `#8c8c95`；强调色只给「运行中」状态点；
- 面板默认只显 4 个，其余折成一行胶囊；
- 标题右侧漏斗图标打开「管理面板」浮层，逐个开关控制哪些面板出现在侧栏。

## 交互

- 点分组标题收起/展开；面板标题右侧漏斗 = 管理面板；
- 「显示其余 N 个」展开/收起面板列表；
- 管理浮层里可逐个开关，或一键全部隐藏 / 全部显示。
