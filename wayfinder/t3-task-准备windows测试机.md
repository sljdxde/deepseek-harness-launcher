## Question

移植讨论要用真实保真度说话，但开发机是 macOS。人类需要把一台可装包、可跑 GUI 验证、可访问 GitHub 的 **Windows 实体机或虚拟机**（Win10 1903+ / Win11）准备就绪。这是决策链的硬前提：没有它，栈路线原型票只能纸上谈兵。

完成标准：
- 一台 Windows 机器可远程或当面操作，已装浏览器（Chrome/Edge 任一）；
- 能安装/卸载自打包的 GUI 程序，能开任务管理器/事件查看器观察进程；
- 网络可拉 GitHub Releases 与 npm registry（或明确记录镜像限制）。

解决时记录：机器形态（实体/VM、版本、规格）、操作方式（怎么触达）、网络限制。后续原型与验收票都依赖这份事实。
