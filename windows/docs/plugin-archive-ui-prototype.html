落地说明

① 面板从居中小弹窗改为整页视图：现有代码把弹窗渲染进 dsh 的 main slot，弹窗套面板层级怪异；整页铺满内容区后与 magpie 插件页同构，宽屏下卡片栅格才有意义。
② 颜色全部映射 --dsw-alias-* 语义 token（原型中的静态色板仅作展示），深浅主题跟随 dsh 设置，与现有开关、角标同一套来源。
③ 功能面不变：插件管理的更新检测 / 批量更新 / 忽略 / 框选 / 停用开关 / 损坏清理、安装与更新队列、dev-linked 二选一确认全部保留，只是重排；归档管理的搜索为新增（数据本地过滤，不加接口）。
④ 市场加载与打开面板时先渲染 ghost 骨架，数据到位后逐张入场；手动安装行对应现有 install 接口的 url 参数，文件夹按钮依赖宿主 picker 能力，没有时隐藏。
