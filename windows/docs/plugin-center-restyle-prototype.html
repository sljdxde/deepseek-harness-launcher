这一版改了什么（相对上一版）

1. 色彩纪律：图标块回归 magpie 的灰底中性图标（shadow-tile 双层细描边），不再按分类上色；chip 灰底、分类名只允许低饱和色相出现在文字上；绿只给「已安装 / 更新」；accent 只给「可安装 / 选中计数」。整页第一眼是灰阶 + 一点蓝，不再满屏彩色小块。
2. 密度：卡片内距 16→12px、栅格间距 14→10px、行高收紧，一屏信息量提升（magpie 的紧凑节奏）。
3. 按钮：全站统一 pm-act 体系——灰 pill（次级）、淡 accent（安装）、绿字（已安装）、busy 灰字 + 转圈；圆角 13px 胶囊、h26、min-width 64。
4. 分类 tab：iOS segmented 式——选中的是白色 thumb 浮块（seg-edge 阴影），其余纯文字；计数弱化，选中计数变 accent。
5. 圆角阶梯统一：卡片 12 / 图标块 10（大 12）/ 按钮 13 / chip 5 / 输入 7-8——不再一元素一个值。
6. 图标体系换 Tabler（MIT）：24 网格 / 2 描边 / currentColor，全站纯黑，不再按分类上色；分类靠形状语义区分，同一分类内按插件功能给不同图标（侧栏 / 终端 / 归档 / 参数面板 / 知识库…）。所有图标都做了光学归一：按内容包围盒统一缩放并精确居中，因此各图标视觉大小一致、线宽一致、在图标块里真正居中。键名与插件管理器共用一套词汇，后续可机械对齐。完整图标库见 plugin-icon-library.html（25 类 × 200+ 图标，含白天/夜晚两态）。
7. 明暗双模式：顶栏新增切换按钮，墨色令牌随之反演（白天近黑、夜晚近白），流光描边、遮罩、浮窗一起换肤。
