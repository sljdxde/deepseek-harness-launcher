插件中心图标库 · 黑白版

图标取自 Tabler Icons（MIT 许可，24 网格 / 2 描边 / currentColor）：全部 outline 线性风格，一律黑白，不按分类上色；分类靠形状语义区分，同一分类内按插件实际功能给不同图标（工程向：终端、容器、拓扑、仪表盘…）。 颜色只有「墨色」一档，由 --ink 控制，白天近黑、夜晚近白。
