四 · 更新弹窗：区分 DHL 与 dsh

两条链路各自独立，弹窗标题、版本对比、说明来源都不同，避免用户搞混。

DHL
启动器更新可用
正式版
v0.3.11 → v0.4.0
来源：GitHub Release · 2026-11-08
更新说明
· 任务栏红色未读角标
· 托盘面板替换右键菜单
· 默认使用国内镜像源
① DHL 自身更新（替换 exe）
dsh
Deepseek Harness 更新可用
候选版
v0.2.2-rc.1 → v0.2.3
来源：GitHub Release · 2026-11-07　｜　npm latest
可更新到：v0.2.3 ▾ （共 2 个版本）
更新说明
· 会话分叉稳定性修复
· 插件 API 小幅变更
⚠ 更新会重启 Harness；旧运行环境保留为回退快照
② dsh 运行环境更新（重装 runtime）
两处关键区别（防止混淆）：
· 标题：DHL 用「启动器更新可用」，dsh 用「Deepseek Harness 更新可用」——不写「更新」两个字就不知道更的是谁。
· 图标：DHL 用品牌蓝方块，dsh 用墨绿方块，扫一眼就能分。
· 动作：DHL 是「下载并安装」（替换 exe 后重启）；dsh 是「更新到 vX」（重装 runtime，保留回退快照）。
· 通道：dsh 会标「正式版/候选版/公测版/内测版」，DHL 只有「正式版/提测」。
