五、为什么必须画进图标

这台机器的 shell 不接受 overlay 角标。
裸 Win32 探测结果（不是本项目的代码）：
ITaskbarList3 → CoCreateInstance hr=0x80004002 (E_NOINTERFACE)
ITaskbarList4 → SetOverlayIcon FAIL hr=0x80004005 (E_FAIL)
overlay 是 Windows 官方画角标的方式，但这里用不了，所以只能把数字合成进图标位图本身。
副作用（需要你知道）
画进图标意味着要覆盖快捷方式的 IconLocation：任务栏图标会指向 %LOCALAPPDATA%\DHL\taskbar.ico，而不是 exe 自带图标。
数字变化时这个 ico 会被重写并通知 shell 刷新。Explorer 有时延迟 1–2 秒才重绘，属于 shell 缓存行为。

六、角标位置：两个候选

右下
方案 A：图标内部右下角（当前实现）
Windows 通知角标的惯例位置。鸟形图案偏中上，右下是空白，不遮挡主体；缩到 16px 时最清晰。
右上
方案 B：图标内部右上角
与 macOS 菜单栏角标位置一致。但这只图标右上正好是鸟的翅膀，角标会压住图形，16px 下容易糊。
建议：右下角。Windows 用户对任务栏角标在右下已有肌肉记忆，而且这张图标的右上正好是翅膀，压上去会脏。
