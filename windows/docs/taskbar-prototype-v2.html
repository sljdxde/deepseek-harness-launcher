DHL Windows 任务栏：两个功能的真实根因 + 原型

这一版不是重新设计 UI，而是先修掉三个已经确认的断裂点。每一节都写明「实测证据 → 根因 → 修法」。

一、先说结论：为什么之前两版都没修好

根因 1｜左键点击无效：固定的快捷方式指向旧路径，且没有参数。
实测你的固定按钮快捷方式是：
target = D:\003代码目录\deepseek-harness-launcher\windows\build\DHL.exe
args   = （空）
而应用现在装在 %LOCALAPPDATA%\Programs\DHL\，build\DHL.exe 已被替换。
点它 = 启动一个旧副本，且没有 --open，即使启动也不会去开浏览器。
根因 2｜角标不显示：这台机器的 shell 明确拒绝 overlay 图标。
独立 COM 探测（裸 Win32，不是我的代码）：
ITaskbarList  : OK
ITaskbarList2 : OK
ITaskbarList3 : CoCreateInstance hr=0x80004002 (E_NOINTERFACE)
ITaskbarList4 : OK
换 ITaskbarList4 再试：HrInit OK / AddTab OK / SetOverlayIcon FAIL hr=0x80004005 (E_FAIL)
结论：这台机器拿不到 overlay。所有「用 SetOverlayIcon 画角标」的路都走不通，只能把数字画进图标本体。
根因 3｜画进图标的角标，被固定按钮忽略了。
WM_SETICON 只改窗口图标；任务栏上的固定按钮读的是快捷方式的 IconLocation。
之前虽然写了 taskbar.ico，但只更新了「开始菜单」和「桌面」两份快捷方式——固定按钮那份漏了。
现已补进 shortcutPaths()，但还缺一次强制刷新。

二、角标：唯一可行的做法

overlay 不可用，就把数字合成进图标位图，然后让所有快捷方式（含固定按钮那份）都指向这个 ico，再通知 shell 刷新。

三、角标的五种状态（放大看细节）

无未读 基准

图标原样，不加任何东西。固定按钮和运行中都一样。

1–9 条 一位数

红色胶囊贴在右下角，白字。胶囊高度约图标的 52%，保证缩到 16px 还能认。

10–99 条 两位数

胶囊自动变宽（不压扁文字），宽度按位数算。

100+ 封顶

显示 99+，与 macOS 版 BadgeText 规则一致；胶囊宽度有上限，不会盖住整个图标。

四、左键点击：修好之后的行为

左键的目标只有一个：把 dsh 界面送到你眼前。不弹面板、不弹列表、不管有多少未读。

这条链路已经实测通了。手动执行 DHL.exe --open，日志立即出现：
startup action: open → activated browser window (hwnd=198542) → browser already showing Harness (clients=4, visible=true); activated instead of reopening
所以左键要修的只有一件事：把固定按钮的快捷方式重写对。

五、要改的地方（三处）

改动做什么为什么必须这么改
① 校验并重写固定快捷方式
taskbar.go		 启动时把固定按钮那份 .lnk 也纳入校验：目标不是当前 exe、或参数不是 --open，就重写。 现在只在「目标不匹配」时重写，而固定那份压根不在检查范围。这是左键点了没反应的直接原因。
② 强制刷新 shell 图标
taskbaricon_windows.go		 写完 taskbar.ico 后，除 SHChangeNotify 外，对固定快捷方式做一次 IconLocation 重写 + 图标缓存刷新。 Explorer 缓存固定按钮图标，光改文件不通知，界面上不变。这是角标「写了但看不见」的最后一环。
③ 图标合成为主路径
taskbarbadge_windows.go		 保留 SetOverlayIcon 尝试（有则更清晰），失败时不再依赖它；图标合成从 fallback 升为主路径。 实测本机 E_FAIL，overlay 永远不会有结果。现在代码把 overlay 当主路径，时序也不对。

六、需要你确认的三点

① 角标位置：现在放右下角（macOS 菜单栏是右上角）。Windows 任务栏惯例是右下角，且右下角不易被图标本身图形遮挡。要改右上角吗？

② 点固定按钮时如果 dsh 没在跑：应该 ①直接开浏览器（白屏等启动），还是 ②先启动 dsh、就绪后再开浏览器？现在是②。

③ 未读数来源：角标数字取自 /dsh-session-notify/events 的未读数。统计「已完成但没看的会话」，还是「所有未读事件」？现在按前者。
请确认后我再改代码。另外：你的固定按钮快捷方式目前指向 build\DHL.exe，代码改完后安装时会一并重写，你不需要手动重新固定。
